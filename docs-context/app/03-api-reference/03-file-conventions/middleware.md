The `middleware.js` file convention has been **deprecated** in Next.js 16 and renamed to [`proxy.js`](./proxy.md).

All functionality remains the same — only the file and export names have changed. See the [Migration to Proxy](./proxy.md#migration-to-proxy) section for details on how to migrate.

You can automatically migrate by running:

```bash
npx @next/codemod@canary middleware-to-proxy .
```

For full documentation, see the [`proxy.js` API reference](./proxy.md).
